# 115 年度智慧節能家電・空調專區　冷氣機型比較表

中華電信寬頻優惠專案「空調專區」冷氣機型比較表，單一 HTML 檔（`index.html`），
可直接用瀏覽器開啟、並最佳化為 **A3 橫式黑白列印**、字體與排版適合 **65 歲以上長者閱讀**。

## 內容
- 資料來源：（公告版）115 年度智慧節能家電資料總表，製表時間 2026/07/10 09:12
- 收錄範圍：**空調專區「上架中」機型共 313 款**，9 大品牌
  （SAMPO 聲寶、HERAN 禾聯、TECO 東元、Tatung 大同、Panasonic、三菱電機、HITACHI 日立、DAIKIN 大金、三菱重工）

## 兩種比較方式
1. **比較方式一　同噸數（KW／坪數）跨品牌比較**
   依冷氣能力 KW（對應適用坪數）分 7 個級距（2.0kW～9.1kW 以上），
   將各品牌同級距機型並列，橫向比較功能與價格。
2. **比較方式二　同一廠商 2–10KW 全系列比較**
   以品牌為單位，列出該廠商全系列機型（依 KW 由小到大），縱向挑選坪數。

## 列印說明
- 版面：**A3 橫式**，瀏覽器列印時請選 A3、橫向、開啟「背景圖形」。
- 針對黑白列印最佳化：黑框粗格線、深色表頭、粗體價格，避免以顏色區分。
- 每一頁皆含警語橫幅與固定頁尾警語。
- 表頭於跨頁時自動重複。

## 圖片說明
- 各品牌代表圖為**向量示意圖（線稿）**，用於辨識機型類別（壁掛分離式／窗型／一對多），
  **非實際外觀，僅供參考**。（此環境無法穩定取得各品牌原廠照片，且照片於黑白列印易糊化，
  故採高對比示意圖以確保列印清晰。）
