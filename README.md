中華電信寬頻優惠專案「空調專區」冷氣機型比較表。字體與排版適合 **65 歲以上長者閱讀**、
彩色呈現、且**黑白列印仍高對比**。

### 彩色 × 黑白列印
彩色主題（方式一青、方式二莓、封面深藍）皆採「深底白字／淺底深字」，靠明暗（非色相）區分，
並以 `print-color-adjust:exact` 強制列印背景色，黑白雷射印出照樣對比分明。

## 兩種比較方式
1. **比較方式一　同噸數（KW／坪數）跨品牌比較**
   依冷氣能力 KW（對應適用坪數）分 7 個級距（2.0kW～9.1kW 以上），
   將各品牌同級距機型並列，橫向比較功能與價格。
2. **比較方式二　同一廠商 2–10KW 全系列比較**
   以品牌為單位，列出該廠商全系列機型（依 KW 由小到大），縱向挑選坪數。

## 篩選功能（螢幕操作）
頁面最上方有篩選列（黃色區塊，**列印時自動隱藏**），可依下列條件即時篩選，
**兩種比較表會同步套用**，無符合資料的級距／品牌整頁自動隱藏：
- **冷／暖**：全部／冷暖兩用／僅冷氣
- **寬頻優惠價**：2 萬以下／2–3 萬／3–5 萬／5 萬以上
- **品牌**：9 大品牌可複選
- **功能**：WiFi智慧／自動清潔／空氣清淨／抗菌防霉／單獨除濕（需全部包含）
- 篩選後可**直接列印篩選結果**（隱藏的機型不會印出）。

## 列印說明
- 版面：**A3 橫式**，瀏覽器列印時請選 A3、橫向、開啟「背景圖形」。
- 針對黑白列印最佳化：黑框粗格線、深色表頭、粗體價格，避免以顏色區分。
- 每一頁皆含警語橫幅與固定頁尾警語。
- 表頭於跨頁時自動重複。

## 圖片說明
- 各品牌代表圖為**向量示意圖（線稿）**，用於辨識機型類別（壁掛分離式／窗型／一對多），
  **非實際外觀，僅供參考**。（此環境無法穩定取得各品牌原廠照片，且照片於黑白列印易糊化，
  故採高對比示意圖以確保列印清晰。）
